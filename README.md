# 📊 Sentiment Analysis Dashboard

## 📝 Project Description
This project analyzes user reviews by cleaning and preprocessing the data, using a fine-tuned Hugging Face model for sentiment prediction, and visualizing insights through an interactive Streamlit dashboard.

---

## 🚀 Features
- Dynamic filtering (Source, Sentiment, Month)  
- KPI metrics (Total, Positive, Negative)  
- Sentiment Distribution (Bar Chart)  
- Sentiment Share (Pie Chart)  
- Rating By Source (Bar Chart)  
- Location Insights (Bar Chart)  
- Key Insights based on filters   
- Sentiment prediction using the trained model  

---

## 🛠 Tech Stack
- Python  
- Streamlit  
- Pandas  
- Matplotlib  
- Hugging Face Transformers  

---

## 📚 Key Learnings
- Built an interactive dashboard using Streamlit  
- Implemented dynamic filtering using Pandas  
- Fine-tuned a Hugging Face transformer model for sentiment classification  
- Applied pretrained NLP model for prediction tasks  
- Designed KPI metrics and visualization dashboards
